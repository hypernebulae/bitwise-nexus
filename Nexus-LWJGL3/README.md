# Bitwise Nexus 3.0-alpha

yo we doing tests with lwjgl now, this is a special frontend for bitwise nexus

this has gpu acceleration now so you can have hundreds of frames a second at high resolution (with a good gpu)

## build and run

```bash
mvn clean compile exec:java
```

## warnings

this is still a very early product. alpha if not pre-alpha. expect some bugs and incomplete features, it may take a while for this product to be anywhere near as customizable as the main game
